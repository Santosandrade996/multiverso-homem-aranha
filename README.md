# 🕸️ Multiverso Homem-Aranha

Um projeto interativo desenvolvido com **HTML, CSS e JavaScript**, inspirado no universo do Homem-Aranha. A ideia é criar uma experiência visual divertida com um carrossel de cards dos personagens do multiverso.

## 🚀 Funcionalidades

- 🎴 Carrossel de cards com personagens do Multiverso Aranha
- 🌀 Animações e efeitos de rotação com CSS
- 🖱️ Interações com clique para girar os cards e revelar informações
- 📱 Responsivo para diferentes tamanhos de tela

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
